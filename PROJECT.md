# Oak Park Transit Dashboard

A simple, mobile-friendly dashboard for getting around Oak Park, Illinois.

Goals:
- Show transit stops and routes serving Oak Park on a map (Leaflet + OpenStreetMap).
- List nearby stops and the routes that serve them.
- Work at phone widths (360px and 390px) and follow the system light/dark scheme.

Data: static GTFS-derived JSON in data/ (source URLs and retrieval dates in data/SOURCES.md).
Status: data source still being sourced; see SOURCES.md.
